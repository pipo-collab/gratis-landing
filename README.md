# GRATIS®2026 — Landing

Sitio estático (HTML + CSS + JS, sin dependencias ni build).

```
index.html          ← la landing
assets/img/         ← imágenes, favicon y og.jpg (preview para redes)
```

## Editar textos
Todo el contenido está en `index.html`. Buscá el texto y reemplazalo.

## Pendientes antes de lanzar
- [ ] Reemplazar `mailto:[EMAIL]` por el mail real (botón "Agendar un café").
- [ ] Cuando tengas el dominio final, cambiar `assets/img/og.jpg` en la etiqueta
      `og:image` por la URL completa (ej. `https://estoesgratis.com/assets/img/og.jpg`)
      para que WhatsApp / LinkedIn muestren la imagen al compartir.

## Deploy
Conectado a Vercel: cada cambio que se sube a la rama `main` se publica solo.
